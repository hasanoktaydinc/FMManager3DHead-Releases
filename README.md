# FM Manager 3D Head – versions

This repository only lists the version numbers of FM Manager 3D Head, for the plugin's built-in update check.
There is nothing to download here; the plugin is available on its website.

Each release's tag is a version (for example `v0.26.0`). Put the website's download link in the release description: the plugin's "New version" button opens the first link it finds there.
